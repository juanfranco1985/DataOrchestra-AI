# Manual operativo DataOrchestra AI

Este manual explica como usar DataOrchestra AI como herramienta interna de diagnostico comercial para PyMEs.

## Orden de lectura

1. `00_paso_a_paso_conductor.md`: vision completa, como conductor de una herramienta nueva.
2. `01_requisitos_y_software.md`: software necesario e instalacion.
3. `02_archivos_necesarios.md`: que datos pedir al cliente.
4. `03_carga_de_datos.md`: donde poner los archivos y que no hacer.
5. `04_ejecucion_cli_powershell.md`: comandos por PowerShell.
6. `05_panel_visual_local.md`: uso opcional con panel Streamlit.
7. `06_modelos_de_analisis.md`: tipos de analisis disponibles.
8. `07_revision_entrega_y_cierre.md`: revision humana, PDF, devolucion y cierre.
9. `08_solucion_de_problemas.md`: errores frecuentes.
10. `09_checklist_operativo.md`: checklist para cada cliente.

## Regla central

No guardar datos reales dentro del repositorio. Usar un runtime externo y trabajar solo con datos anonimizados.
