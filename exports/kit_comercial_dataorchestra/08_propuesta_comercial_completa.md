# Propuesta comercial piloto - DataOrchestra AI

## Posicionamiento

DataOrchestra AI es un servicio supervisado de diagnostico comercial para PyMEs que ya tienen datos simples en planillas, sistema de facturacion, POS o exportaciones CSV.

No se vende como SaaS, plataforma autoservicio ni promesa de aumento de ventas. Se vende como una revision inicial, prudente y accionable para entender mejor ventas, margen y stock.

## Frase corta para explicar el servicio

Ayudo a comercios y PyMEs a transformar datos simples de ventas, productos y stock en un diagnostico claro, con hallazgos concretos y recomendaciones practicas. El informe se revisa manualmente antes de entregarse y se trabaja solo con datos anonimizados.

## Cliente ideal inicial

- Comercio o PyME de baja complejidad.
- Tiene ventas registradas en Excel, sistema de facturacion, sistema de gestion o POS.
- Puede exportar o armar tres archivos: `ventas.csv`, `productos.csv` y `stock.csv`.
- Quiere entender margen, productos fuertes, stock critico, productos lentos o concentracion de ventas.
- Acepta trabajar con datos anonimizados.
- No espera garantias de resultado ni integraciones inmediatas.

## Clientes a postergar

- Negocios sin datos registrados.
- Clientes que no pueden anonimizar la informacion.
- Clientes que exigen resultado garantizado.
- Clientes con datos legales, fiscales, laborales, medicos o financieros sensibles.
- Empresas que necesitan integracion directa con sistemas desde el inicio.

## Oferta principal

### Diagnostico Comercial Inicial

Incluye:

- revision de alcance y rubro;
- validacion de datos anonimizados;
- control de privacidad y estructura;
- analisis de ventas, margen, stock, concentracion y periodos;
- alertas comerciales priorizadas;
- recomendaciones respaldadas por evidencia;
- informe ejecutivo revisado;
- devolucion breve para explicar hallazgos.

No incluye:

- carga manual extensa de datos;
- limpieza compleja de planillas desordenadas;
- integracion con sistemas;
- asesoramiento contable, fiscal, legal o financiero;
- garantia de mejora de ventas, margen o rentabilidad;
- seguimiento mensual salvo acuerdo posterior.

## Precios recomendados para validacion local

Estos precios son para la etapa inicial en San Jose del Rincon, Santa Fe y zona cercana. Conviene revisarlos cada 30 dias por inflacion y esfuerzo real.

### Opcion A - Piloto fundador

Precio sugerido: ARS 25.000.

Uso recomendado:

- solo para los primeros 2 o 3 clientes reales;
- idealmente con clientes conocidos, referidos o comercios de bajo riesgo;
- sirve para validar valor, tiempos, objeciones y calidad de datos.

Condicion:

- dejar claro que es precio piloto/fundador;
- no convertirlo automaticamente en precio normal;
- pedir feedback y permiso para usar el caso como aprendizaje interno.

Lectura comercial:

ARS 25.000 es barato para el trabajo tecnico si el diagnostico lleva mas de 2 o 3 horas. Puede usarse como puerta de entrada, pero debe tener alcance muy cerrado.

### Opcion B - Diagnostico inicial normal

Precio sugerido: ARS 45.000 a ARS 75.000.

Uso recomendado:

- despues de los primeros pilotos;
- cuando el cliente ya entiende que recibe un informe revisado;
- si el negocio tiene datos razonablemente ordenados.

Alcance:

- un diagnostico;
- hasta tres archivos base;
- una devolucion breve;
- una ronda de aclaraciones.

### Opcion C - Diagnostico con mayor esfuerzo

Precio sugerido: ARS 90.000 a ARS 150.000.

Uso recomendado:

- datos mas desordenados;
- mas categorias o mayor volumen;
- necesidad de mas interpretacion humana;
- devolucion mas extensa.

No ofrecer como primera opcion a comercios chicos salvo que el esfuerzo lo justifique claramente.

## Seguimiento mensual

### Plan mensual inicial

Precio sugerido: ARS 50.000 a ARS 70.000 por mes.

Incluye:

- una actualizacion mensual con datos nuevos;
- comparacion contra periodo anterior;
- revision de alertas y recomendaciones;
- informe corto;
- una conversacion breve de seguimiento.

Condiciones:

- ofrecer solo despues de un primer diagnostico;
- usar el mismo formato de archivos;
- no incluir carga manual pesada;
- no incluir integraciones;
- ajustar precio si aumenta el esfuerzo o cambia el alcance.

Lectura comercial:

ARS 50.000 mensuales no es alto si el cliente recibe seguimiento real y el proceso ya esta ordenado. Para una PyME muy castigada puede sentirse sensible, por eso conviene venderlo como continuidad opcional, no como requisito para empezar.

## Recomendacion de estrategia de precios

1. Primeros 2 o 3 pilotos: ARS 25.000 con alcance cerrado.
2. Precio base posterior: ARS 45.000 a ARS 75.000 por diagnostico.
3. Mensual opcional: ARS 50.000 a ARS 70.000 solo si el cliente ya recibio valor.
4. Validez de precio: 15 a 30 dias.
5. Revision mensual de precios por inflacion, demanda y tiempo real invertido.

## Guion breve para venderlo

Tengo una herramienta para hacer un diagnostico comercial inicial con datos simples que muchos comercios ya tienen: ventas, productos y stock.

No te pido datos personales ni informacion sensible. Primero revisamos si tus archivos sirven y si estan anonimizados. Si pasan esa validacion, preparo un informe con los principales hallazgos: productos que mas pesan, margenes bajos, stock critico, productos lentos y recomendaciones practicas.

No es una promesa de vender mas ni una plataforma automatica. Es una forma ordenada de ver que dicen tus datos para tomar mejores decisiones.

Para los primeros comercios estoy ofreciendo un piloto fundador con precio reducido y alcance cerrado. La idea es que puedas probarlo sin meterte en un proyecto grande.

## Respuesta a objeciones

### Es caro

Entiendo el contexto. Por eso el primer diagnostico tiene alcance limitado y precio piloto. La idea es encontrar informacion util con datos que ya tenes, sin cambiar sistemas ni iniciar un proyecto grande.

### No se si mis datos sirven

Ese es justamente el primer paso. Antes de cobrar o avanzar en serio, revisamos si los datos tienen estructura suficiente y si no incluyen informacion sensible.

### Tengo todo en Excel

Perfecto. Si la planilla tiene ventas, productos y stock con columnas claras, puede servir como punto de partida.

### No quiero compartir datos sensibles

No necesito datos personales. El proceso esta pensado para trabajar con datos anonimizados. Si aparece informacion sensible, el analisis se detiene.

### Que gano con esto

Un informe claro para ver donde se concentra la venta, que productos pueden estar dejando poco margen, donde hay riesgo de stock y que acciones conviene revisar primero.

## Cierre comercial recomendado

Si te parece, hacemos primero una revision de admision: rubro, tipo de datos que tenes y si podes anonimizar la informacion. Si los datos sirven, avanzamos con el diagnostico piloto. Si no sirven, te lo digo antes de prometer un resultado.

## Regla interna

No aceptar mas de 2 o 3 pilotos baratos en paralelo. El objetivo de la etapa piloto es aprender y validar, no quedar atrapado en mucho trabajo manual de bajo precio.
