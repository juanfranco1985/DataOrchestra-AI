# DataOrchestra AI - Diagnostico comercial para PyMEs

## Que es

Un servicio supervisado para analizar datos simples de ventas, productos y stock, y convertirlos en un informe claro con hallazgos y recomendaciones.

## Para quien es

Comercios y PyMEs que ya registran ventas, productos o stock en Excel, sistema de facturacion, sistema de gestion o POS.

## Que puede detectar

- Productos que mas venden.
- Productos con margen bajo.
- Stock bajo o critico.
- Stock parado o excesivo.
- Concentracion de ventas.
- Cambios entre periodos.
- Recomendaciones practicas para revisar.

## Que datos se necesitan

- Ventas.
- Productos.
- Stock.

Formato ideal: CSV o planillas exportables.

## Privacidad

No se necesitan datos personales. No enviar nombres de clientes, telefonos, emails, DNI, CUIT/CUIL personales, direcciones, tarjetas ni cuentas bancarias.

## Entregable

Informe ejecutivo revisado con metricas, alertas, recomendaciones, evidencia y limitaciones.

## Precio piloto

ARS 25.000 para primeros comercios, con alcance cerrado.

## Importante

No es una promesa de vender mas. No reemplaza al contador ni al sistema de gestion. Es una herramienta para entender mejor el negocio con datos que ya existen.
