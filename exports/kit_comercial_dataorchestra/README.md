# Kit comercial DataOrchestra AI

Este kit resume como presentar DataOrchestra AI en conversaciones negocio a negocio, con una version simple para venta en calle y una version tecnica para profundizar cuando el cliente pregunte.

## Orden de uso recomendado

1. Leer `01_discurso_simple_calle.md` antes de salir a visitar comercios.
2. Usar `02_discurso_tecnico_profundo.md` para responder preguntas de dueños, administradores o perfiles mas tecnicos.
3. Tener a mano `03_preguntas_y_objeciones.md` durante llamadas o reuniones.
4. Usar `04_precios_y_paquetes.md` para no improvisar precios.
5. Completar `05_checklist_primer_contacto.md` despues de cada charla.
6. Enviar o leer `06_mensaje_whatsapp_y_email.md` cuando el cliente pida mas informacion.
7. Practicar `14_entrevista_preguntas_y_respuestas.md` para responder desde preguntas simples hasta preguntas tecnicas, legales y comerciales complejas.

## Regla principal

No venderlo como plataforma automatica ni como promesa de mejora garantizada. Presentarlo como diagnostico comercial supervisado con datos anonimizados.
