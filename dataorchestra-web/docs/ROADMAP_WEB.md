# Roadmap web

## v0.1 - Landing institucional

Landing de una página para explicar el proyecto, su estado real, beneficios, privacidad y piloto controlado.

## v0.2 - Página de servicios

Detalle del diagnóstico piloto, alcance, entregables, requisitos de datos y criterios de admisión.

## v0.3 - Caso demo con dataset ficticio

Página con ejemplo completo usando datos simulados, sin datos reales de clientes.

## v0.4 - Formulario funcional

Integración con email, webhook o backend propio para recibir solicitudes.

## v0.5 - Blog educativo

Contenido sobre ventas, margen, stock, calidad de datos y decisiones comerciales para PyMEs.

## v0.6 - Página de privacidad y términos

Explicación formal del uso de datos anonimizados, alcance del servicio, limitaciones y responsabilidades.

## v0.7 - Integración con CRM/email

Registro y seguimiento de leads con flujo comercial controlado.

## v0.8 - Panel privado para pilotos

Área privada para seguimiento de pilotos, estado de revisión y entregables aprobados.

## v1.0 - Sitio comercial listo para captación controlada

Web lista para captación de clientes piloto, con formularios funcionales, privacidad, caso demo y operación comercial definida.
