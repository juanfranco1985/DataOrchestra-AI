# Checklist 01 - Admision del cliente

- [ ] Cliente entiende que es un piloto controlado.
- [ ] Alcance limitado definido por escrito.
- [ ] Rubro y datos esperados identificados.
- [ ] Autorizacion para procesar datos anonimizados recibida.
- [ ] No hay datos personales necesarios para el diagnostico.
- [ ] Se explicaron limites: no hay resultados garantizados.
- [ ] Se explico que el informe requiere revision humana.
