# Checklist 04 - Revision humana

- [ ] Las metricas principales tienen sentido de negocio.
- [ ] Las alertas tienen evidencia verificable.
- [ ] Las recomendaciones no prometen resultados garantizados.
- [ ] No hay datos personales en el informe.
- [ ] Las limitaciones estan visibles.
- [ ] El borrador `reports/diagnostico_borrador.md` fue revisado contra `reports/diagnostico_borrador.json`.
- [ ] El informe fue revisado por una persona responsable.
- [ ] La aprobacion quedo registrada en `diagnostics/review/approval_record.json`.
- [ ] El entregable aprobado existe en `reports/diagnostico_aprobado.md`.
- [ ] El estado solo cambia a `approved_for_delivery` con aprobacion explicita.
