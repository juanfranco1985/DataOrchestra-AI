Megazzonia Social Ops Privacy Policy

Last updated: June 3, 2026

Megazzonia Social Ops is a personal productivity application intended to help the user review technical project activity, prepare LinkedIn post drafts, and publish approved posts to the user's personal LinkedIn profile.

Information We Access

The application may access the following information only after the user grants authorization:

  • GitHub repository metadata and activity selected by the user, such as repository names, commits, issues, pull requests, and release information.
  • LinkedIn account identity information required for authentication.
  • LinkedIn publishing permission approved by the user, used to publish content to the user's personal LinkedIn profile.
  • Post drafts, captions, screenshots, and publishing metadata created or approved by the user.

How We Use Information

Information is used to:

  • Generate and display technical post drafts based on user-selected project activity.
  • Notify the user about relevant project events and pending drafts.
  • Publish LinkedIn posts only after user approval.
  • Maintain an internal record of draft and publication status.

What We Do Not Do

  • We do not collect or store LinkedIn passwords.
  • We do not sell personal data.
  • We do not publish to LinkedIn without user authorization and approval.
  • We do not use LinkedIn access to post to company pages unless the user separately configures and authorizes that feature.

Data Storage

Access tokens, drafts, screenshots, and settings may be stored by the application or its backend only as needed to provide the authorized functionality. Sensitive tokens should be stored securely and should not be embedded directly in the Android application package.

User Control

The user can disconnect GitHub or LinkedIn at any time. LinkedIn permissions can also be revoked from the user's LinkedIn account settings. GitHub permissions can be revoked from the user's GitHub account settings.

Data Sharing

The application does not sell or share user data with third parties for advertising. Data is sent to LinkedIn or GitHub only when necessary to perform actions authorized by the user.
