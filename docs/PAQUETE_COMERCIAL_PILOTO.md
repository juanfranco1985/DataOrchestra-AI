# Paquete comercial - Piloto controlado

## Posicionamiento

DataOrchestra AI se ofrece como servicio supervisado de diagnostico comercial para PyMEs.

No se ofrece como SaaS, plataforma autoservicio ni producto automatizado sin supervision.

## Cliente ideal para el piloto

- PyME con ventas, productos y stock exportables a CSV.
- Operacion comercial simple o moderadamente simple.
- Responsable disponible para explicar contexto del negocio.
- Disposicion a trabajar con datos anonimizados.
- Expectativa realista: entender mejor el negocio, no garantizar resultados.

## Cliente que conviene rechazar o postergar

- Cliente que exige resultados garantizados.
- Cliente que no puede anonimizar datos.
- Cliente con urgencia legal, fiscal, financiera, laboral o medica.
- Cliente que requiere integraciones complejas desde el primer contacto.
- Cliente que espera autoservicio inmediato.

## Entregables del piloto

- Validacion inicial de datos.
- Registro de privacidad, integridad y auditoria.
- Diagnostico comercial sobre ventas, margen y stock.
- Alertas priorizadas.
- Recomendaciones respaldadas por evidencia.
- Informe ejecutivo aprobado.
- Limitaciones y proximos pasos.

## No incluido en el piloto

- Integracion con sistemas del cliente.
- Panel autoservicio.
- Limpieza manual extensa de datos desordenados.
- Garantia de resultados comerciales.
- Asesoramiento legal, fiscal, contable o financiero.
- Analisis predictivo avanzado.
- Seguimiento mensual, salvo acuerdo posterior.

## Mensaje comercial recomendado

DataOrchestra AI permite ejecutar un diagnostico comercial inicial, controlado y revisado, usando datos anonimizados de ventas, productos y stock. El objetivo es encontrar hallazgos accionables sin iniciar todavia un proyecto tecnologico grande.

## Criterio de exito

El piloto se considera exitoso si:

- los datos son procesables;
- el cliente entiende al menos tres hallazgos;
- el informe ayuda a tomar decisiones concretas;
- el esfuerzo operativo permite repetir el servicio;
- el cliente ve valor suficiente para continuar o pagar una siguiente etapa.
