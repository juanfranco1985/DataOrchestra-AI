# Protocolo de admision del primer cliente

Aceptar solo un cliente de bajo riesgo.

## Requisitos

- Negocio pequeno o mediano con datos simples de ventas, productos y stock.
- Interlocutor dispuesto a revisar resultados con contexto humano.
- Datos anonimizados desde el origen.
- Autorizacion explicita para uso en piloto.
- Entendimiento de que el piloto no garantiza aumento de ventas ni margen.

## Rechazar o postergar si

- El cliente exige resultados garantizados.
- El cliente necesita procesar datos personales.
- El cliente no puede separar datos de venta de datos personales.
- El alcance real supera el diagnostico inicial.
- Hay urgencia legal, fiscal, laboral, medica o financiera.
