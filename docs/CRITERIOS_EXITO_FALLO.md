# Criterios de exito y fallo del piloto

## Exito

- El cliente entrega datos anonimizados y procesables.
- El preflight pasa sin hallazgos de privacidad.
- El diagnostico genera metricas comprensibles.
- El cliente entiende al menos tres hallazgos accionables.
- El cliente percibe valor suficiente para una segunda iteracion o servicio pago.
- El tiempo operativo total es razonable para repetir el proceso.

## Fallo controlado

- Los datos son demasiado incompletos o inconsistentes.
- El cliente no puede anonimizar informacion.
- El informe no aporta decisiones utiles.
- El esfuerzo manual supera el valor comercial esperado.
- El cliente no entiende o no confia en la devolucion.

## Decision

Despues del piloto, registrar una de estas decisiones:

- Continuar con el mismo cliente.
- Ajustar oferta y repetir.
- Cambiar tipo de cliente objetivo.
- Detener desarrollo de plataforma y revisar propuesta.
