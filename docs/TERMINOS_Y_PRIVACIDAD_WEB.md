# Terminos y privacidad web

## Objetivo

Dejar una base publica de terminos y privacidad para acompañar la web institucional de DataOrchestra AI antes de mostrarla a potenciales clientes piloto.

## Ruta publica

```text
/terminos-privacidad
```

## Estado

Implementado como pagina estatica en:

```text
dataorchestra-web/app/terminos-privacidad/page.tsx
```

La pagina cubre:

- estado del servicio como Primer Piloto Real Controlado;
- alcance del diagnostico;
- datos aceptados;
- datos no aceptados;
- uso limitado del formulario de contacto;
- trazabilidad y auditoria;
- retencion y borrado;
- responsabilidad del cliente;
- limitaciones de resultado;
- cambios futuros de terminos.

## Criterio de comunicacion

La pagina mantiene estos principios:

- No presentar DataOrchestra AI como SaaS.
- No prometer autoservicio.
- No prometer automatizacion total.
- No garantizar aumento de ventas, margen o ahorro.
- Reforzar datos anonimizados y revision humana.
- Aclarar que la base necesita revision legal formal antes de operar contratos reales.

## Limitacion importante

Este texto no reemplaza un contrato ni una politica legal revisada por un profesional. Sirve como base institucional y operativa para una primera presencia publica.

## Proximo paso recomendado

Cuando exista un cliente real interesado, convertir esta base en documentos formales:

- contrato o aceptacion de piloto;
- politica de privacidad final;
- acuerdo de tratamiento de datos si corresponde;
- politica de retencion y borrado por cliente.
