# Readiness comercial - DataOrchestra AI v2.0

## Estado actual

DataOrchestra AI v2.0 esta listo para vender o ejecutar como piloto comercial controlado de bajo riesgo.

No debe presentarse todavia como plataforma final autoservicio ni como producto automatizado sin supervision.

## Capacidades operativas listas

- Admision con alcance limitado.
- Recepcion de CSV anonimizados.
- Preflight de privacidad, schema e integridad.
- Bloqueo ante datos sensibles, datos incompletos o cambios posteriores en `raw/`.
- Analisis deterministico de ventas, margen, stock, concentracion, alertas y recomendaciones.
- Borrador ejecutivo en Markdown y anexo tecnico JSON.
- Recomendaciones asociadas a evidencia.
- Aprobacion humana auditable antes de entrega.
- Artefacto aprobado separado del borrador.
- Logs de auditoria por preflight, analisis y aprobacion.

## Condiciones para ofrecerlo comercialmente

- Venderlo como diagnostico inicial asistido, no como plataforma.
- Usar solo clientes de bajo riesgo con datos simples.
- Exigir datos anonimizados desde origen.
- Mantener revision humana obligatoria.
- No prometer aumento de ventas, margen ni ahorro.
- Entregar solo el informe aprobado.
- Registrar feedback, tiempo operativo y objeciones del cliente.

## Aun no es producto final si falta

- Validacion con al menos un cliente real.
- Precio ajustado por esfuerzo real y valor percibido.
- Contrato o aceptacion escrita de alcance, privacidad y limitaciones.
- Repositorio Git formal con CI.
- Segundo caso real para confirmar repetibilidad.
- Panel interno para operacion sin consola.

## Veredicto

Listo para primer piloto comercial controlado.

No listo para escalar como SaaS, plataforma autoservicio o servicio masivo sin supervision.
